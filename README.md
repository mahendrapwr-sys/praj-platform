# PRAJ

## Speak Better. Grow Faster.

PRAJ is an AI-powered English speaking and communication learning platform.

### Features
- AI Voice Conversations
- Grammar Correction
- Pronunciation Analysis
- Vocabulary Builder
- Daily Challenges
- Mock Interviews
- Progress Tracking

### Platforms
- Android
- Web
